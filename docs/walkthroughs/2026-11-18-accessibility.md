# 无障碍真机清单（2026-11-18）

模拟器上已经查过：每个可操作元素有读屏标签（中文、English、Bahasa Melayu）、自己画的按钮至少 44 pt、最大字号（AX5）下核心页面
不重叠不截断、文字和底色的对比度。计划和决定在 `docs/plans/2026-11-18-accessibility-pass.md`。下面这些模拟器验不了，要在真机上
打开对应的系统设置走一遍。

## 旁白（设置 → 辅助功能 → 旁白）

1. **登录和新手引导**：欢迎页从上往下划，贴纸墙不抢焦点，先读到 Apple / Google 登录，再读到「用户协议」「隐私政策」两个链接；
   名字一步的输入框读「名字」。
2. **首页**：小貘舞台读一句话；实时卡每张读成一句（拼车卡不再读出头像里的「M, 杰, H, 林」，也不再在末尾重复一遍标题）；付款卡
   不读「前进」；「列表 / 地图」读出哪个选中了；筛选「全部 / 急 / 塞得进空档」读出选中。
3. **金额和时间读得自然**：「RM 8」「¥50」「1.2 km」「今天 16:00 前」在三种语言下怎么读。要是中文读成「R M 8」，告诉我，
   我改成读屏专用的「8 令吉」。
4. **发悬赏**：标题、类型、赏金、时间每一行读出名字和当前值；选中的时间胶囊读「已选」；发布中读「正在提交」。
5. **申请 / 挑人 / 状态**：卡片的两个操作（打开、申请）在转子「操作」里；挑人时长按的进度有声音或触感提示；状态页每一步读
   「已完成 / 还没到」。
6. **付款和收款方式**：付款弹窗里选中的方式读「已选」；复制按钮读「已复制」；全屏收款码关掉后焦点回到原来那一行。
7. **拼车**：车票读成一句（状态、路线、价钱）；结清时每人的分摊读出金额。
8. **消息**：气泡读「发送中」「没发出去」；红色「!」读「重发」。
9. **问小貘**：半屏打开后焦点落在输入框；关闭按钮读「关闭」；草稿卡的「填进表单」能用。

## 字号（设置 → 辅助功能 → 显示与文字大小 → 更大字体，拖到最大）

- 首页、悬赏详情、发悬赏、付款弹窗、拼车详情、聊天、我的：文字变大、能滚动看到全部，没有文字压在别的文字上。
- 小貘的气泡保持原来大小（决定 A9），旁边的标题和卡片照常变大。

## 减弱动态效果（设置 → 辅助功能 → 动态效果）

- 结清庆祝直接淡入、可点掉；首页卡片摊开、已结清卡飞进贴纸本、距离轴跳到卡片都直接到位；小貘待机动画不循环。

## 增强对比度（设置 → 辅助功能 → 显示与文字大小）

- 灰色说明文字（系统次要文字色，浅色 3.4:1，决定 A7）在打开后变深，读得清。
