**Status:** draft, 2026-10-30 (overnight). Waiting on questions 129–149 (canvas page 「04 问小貘（AI）」, boards

questions are answered; Tasks 1–3 can start with a fake provider.

**Goal:** The 小貘 button opens a working assistant. Before the first cloud call the user consents to Alibaba Cloud Model
Studio (Singapore) for a named purpose. 小貘 drafts a bounty from a sentence, voice or a screenshot into the post form
(with highlight and 撤销), answers questions in the sheet, and translates chat messages. Every cloud call is metered
as 小貘体力 on the server; when 小貘 is hungry the user feeds a 嫩叶 from the pantry or swaps 1 貘币 for one. 小貘记得
keeps places and preferences the user can see, delete and switch off. Every flow keeps its manual path.

**Architecture:** One Supabase Edge Function `ai-draft` in `ap-southeast-1` (`supabase/functions/ai-draft`), the only
caller of the model; it checks consent, the daily limit and energy, calls Qwen through the Model Studio international
endpoint with pinned model IDs and tool schemas, meters tokens, and returns typed drafts. Tables `ai_consents`,
`ai_energy`, `ai_pantry` (ledger-style, server-written), `ai_memory` (user-owned). Speech and the optional on-device
Foundation Models live in `modules/tapiro-kit` with typed result codes and `requestId`-tagged events. Client feature
`src/features/ask/` (sheet, consent, energy, pantry, memory); bounty and chat consume drafts through `src/lib` contracts
so features do not import each other.

**Tech stack:** Expo SDK 57, Supabase Edge Functions (Deno), Qwen on Model Studio Singapore (international), Swift 6
(kit: `SpeechTranscriber` → `DictationTranscriber` → `SFSpeechRecognizer`, `SystemLanguageModel`), bun test, pgTAP.

**Spec:** `docs/specs/2026-10-11-foundation-design.md` (Decisions 「AI path」, 「AI usage (小貘体力)」, 「AI storage」,
「AI labelling」, 「Voice in 问小貘」; Behaviour 「问小貘」; Implementation order 8). AGENTS.md 「AI」. Bounty spec
decision 「Posting entry」 and Implementation order 10. Carpool spec 「Receipt split (later)」. Research:

Story map: `ask.consent.*`, `ask.draft.*`.

## Decided (do not re-ask)

- Cloud path only through an Edge Function in Singapore; no key in the app; Qwen primary, DeepSeek through the same
  Model Studio account as fallback, never DeepSeek direct (AGENTS.md).
- Consent before the first cloud AI call, naming the provider and purpose, recorded with a timestamp (AGENTS.md;
  App Review 5.1.2(i); PDPA). Declining keeps every manual path.
- The AI never performs an action: drafts only; nothing is published, accepted, cancelled or sent without a tap.
- Per-user daily limit enforced in the Edge Function (AGENTS.md); 小貘体力 is the user-facing form of it.
- E2 (KICKOFF 2026-10-11 F17): energy is 小貘's fullness, refilled free at 06:00 Malaysia time to about 3 drafts or 30
  translated sentences, unused free energy resets daily; 1 貘币 → 1 嫩叶 kept in the pantry, never expiring; feeding
  one refills to full. Metered in tokens on the server, never shown as tokens. On-device calls cost nothing (F14).
  "具体交互和 UI 细节到时候再确认" — that is questions 135–141.
- Conversations and drafts stay on the device; 小貘记得 is synced, viewable, deletable, with a switch (foundation).
- No AI label on confirmed drafts ("都不标").
- The ten patterns from 「小貘的 10 种交互做法」 with ⑥ replaced by the sheet (foundation Behaviour).
- Bounty drafting fills the same post form in place, changed fields highlighted, one 撤销 until the user leaves the
  form (bounty 「Posting entry」).
- Voice: microphone button inside the sheet in v1; long-press on the 小貘 button only after a spike (F6).
- Malay always uses the cloud path; Foundation Models is optional and gated on `SystemLanguageModel.default.availability`.
- Speech engine order and en-MY → en-US mapping (AGENTS.md).

## Gaps found while preparing

1. **No account or key exists.** The Model Studio international account, the Singapore workspace and its API key are
   the user's to create (paid service). Tasks 1–3 run against a fake provider in the Edge Function (`AI_PROVIDER=fake`)
   and pgTAP; real calls wait for question 148.
2. **Model IDs drift.** The research named `qwen3.7-flash` and `qwen3.7-plus` (2026-10-04); Qwen renamed models during 2026. Task 1 re-reads the Model Studio model list and pins dated IDs in server config, not in the app.
3. **Energy calibration.** "About 3 drafts or 30 sentences" must become a token budget per model. Ruling: measure
   tokens on 20 recorded prompts per task in Task 1 and set the budget so the median draft costs a third of a full
   belly; the numbers go into server config and a unit test.
4. **Paid energy has no ceiling.** 嫩叶 can be fed without limit, so one user can drive unbounded model cost. Asked as 149.
5. **Withdrawing consent.** PDPA requires that consent can be withdrawn; no surface exists. Asked as 131.
6. **Pantry and coins share the ledger.** Swapping a coin for a 嫩叶 needs a new `coin_reason` (`pantry_swap`) in
   `coin_ledger` and an `ai_pantry` entry in one transaction.
7. **Drafts cross features.** The sheet lives in the shell, the form in `src/features/bounty/post`. Ruling: a draft
   contract in `src/lib/drafts` (typed bounty draft, ride draft later, reply draft); the shell publishes, the post form
   subscribes. No cross-feature import.

## Rulings (overnight, overturnable)

- Overdraw: a call starts when energy > 0 and is never cut off mid-answer; energy floors at 0.
- A failed or timed-out provider call deducts nothing (foundation Errors) and returns a typed `provider_error`.
- Consent record: `ai_consents (user_id, version, provider, purpose, accepted_at, withdrawn_at)`; a new consent
  version (for example DeepSeek fallback or receipts) asks again.
- Requests carry only what the task needs: the user's text, the transcript, a chosen image, the current form's
  fields, and the 小貘记得 entries the tool asks for. Never payee methods or other users' data; chat translation sends
  only the message being translated.
- No prompt or response is stored on the server; only metering rows (user, task, model, tokens, at).
- On-device routing is invisible: no label, no energy, same draft contract (F14).
